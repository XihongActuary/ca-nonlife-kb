再保险与摊回准备金

毛 / 净两套三角形 · 比例与非比例的分摊机制 · 摊回资产的信用维度（教材 Ch11 P252）

定位实务专题 · 净准备金与偿付能力的中间层
一、毛口径与净口径：两套世界 二、比例再保的摊回逻辑 三、非比例再保的摊回逻辑 四、摊回的信用与监管维度 五、考试连接

一毛口径与净口径：两套世界

监管要求净额准备金（扣除摊回），但摊回不是「毛准备金 × 一个折扣」——分摊结构随再保形态完全不同。
维度毛三角形净三角形
赔款内容分出前全部赔款扣除再保摊回后的自留赔款
进展形态反映业务本身被再保结构「再塑造」（超赔层的截断效应）
评估用法定价与业务分析准备金入账、偿付能力（K2 净额口径）
常见错误用毛三角形因子直接套净数据（或反之）——截断改变了进展模式，必须各自成三角形
实务铁律：毛 / 净三角形分别建立、分别评估，摊回 = 毛结果 − 净结果，再做合理性校验（如比例再保下摊回率应近似分出比例）。混装是回溯偏差的经典来源（→CH.04 §4.1 数据问题表）。常考

二比例再保的摊回逻辑

成数（Quota Share）与溢额（Surplus）：按比例分摊每一笔赔款，摊回结构与自留结构同构。
成数再保
摊回赔款(i,j) = 毛赔款(i,j) × 分出比例　（逐笔、逐格成立）
净三角形 = 毛三角形 × 自留比例 → 净进展因子 = 毛进展因子（形状不变）
摊回准备金 = 毛准备金 × 分出比例
溢额再保的变量：每笔保额切成「线数（lines）」，自留额以上部分分出——大额赔案分出比例高，小额全额自留。于是净三角形相对毛三角形「大案被削平」：高进展格的削减多于低进展格，净尾部因子 ≠ 毛尾部因子 × 比例。溢额下必须独立建净三角形，不能偷懒换算。

三非比例再保的摊回逻辑

险位超赔（XL）、事故超赔（CAT XL）、赔付率超赔（Stop Loss）：按触发条件分摊，摊回呈「期权式」的非线性。
形态触发摊回特征对准备金评估的影响
险位超赔 XL单案损失超过起赔点单案封顶（限额），超出部分回归自留净三角形大案被截断 → 需「截断后三角形 + 单独评估超限部分摊回」
事故超赔 CAT XL一次事故累计损失超起赔点按事故聚合，与巨灾模型联动巨灾未决的摊回需事件级模拟（→CH.04 巨灾分离）
赔付率超赔 Stop Loss年度综合赔付率超约定年度结算，未决口径复杂通常作利润平滑工具而非准备金分摊主力
险位超赔单案摊回（算例）
自留 50 万，超赔层 50–150 万（再保承接超过 50 万至 200 万之间）。
单案估损 180 万 → 摊回 = 180 − 50 = 130 万，净自留 = 50 万
单案估损 260 万 → 摊回 = 150 万（层满），净自留 = 110 万（50 + 超层 110）
「层满回归」是超赔摊回的关键非线性：估损从 180 涨到 260，摊回不再增加（层已满）——净未决对估损上修的敏感度反而上升。回溯分析若忽略这一点，超赔业务净偏差会系统性为负（低估）。了解

四摊回的信用与监管维度

摊回是资产（应收款），资产就有信用风险——「再保人赖账」在偿二代里有专门的资本占用。
维度要点
会计口径摊回未决 / 摊回未到期作为资产列示，与净准备金对称（财会15号，→CH.05 §5.2）
信用风险资本偿二代Ⅱ交易对手违约风险模块：按再保人评级与担保状况设定因子，摊回资产越大、信用越弱 → 资本占用越高
再保人集中度单一再保人摊回集中 → 集中度加成；分散高质量再保 panel 是标准做法
评估披露11号令框架下，准备金评估报告应说明摊回的计量基础与再保结构假设
经营闭环（连接 CH.05 §5.4）：再保的三重身份——① 准备金端：降低净未决 → ② 资本端：K2 下降但交易对手违约风险上升 → ③ 决策端：最优再保结构 = K2 节约 − 信用资本占用 − 分保成本。正精算师给管理层的再保建议，就是解这道三元优化题。

五考试连接

考法答题骨架星级
「净准备金如何评估」毛/净分别建三角形 → 各自链梯 → 摊回 = 毛净差 → 与分出比例校验常考
「超赔再保对未决的影响」截断效应 → 单独评估超限部分 → 层满回归的非线性敏感度了解
「摊回的信用风险」资产属性 → 交易对手违约模块 → 集中度与评级因子了解
一句话收束：毛的世界看业务，净的世界看自己；比例再保按尺子分，超赔再保按触发分；摊回是资产，别忘信用那一票资本。
