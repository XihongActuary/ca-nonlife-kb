§4.1数据问题的识别与处理

「垃圾进、垃圾出」——链梯再漂亮也救不了脏数据。教材 Ch2 用一整套真实数据演示数据分组与诊断，这一节是三角形的「洗菜」工序。
数据问题识别信号处理方式不做会发生什么
大赔案 / 巨灾单案占事故年赔款比重异常；某进展格突增从三角形剔除单独评估（或设赔付上限截尾），余量走常规方法进展因子被单案绑架，因子系统性虚高
通胀各事故年首列（12月赔款）逐年趋势性抬升指数化：历史赔款按通胀指数调整到评估日价格水平老事故年按旧价格、新事故年按新价格，进展模式失真
理赔流程变化某列因子整体跳变（如结案提速 → RV 衰减加快）数据分组：变化前后分段；或对受影响列加权近期数据用旧节奏预测新节奏，未决系统性错估
再保口径混装毛赔款与净赔款三角形混用分三角形：毛/净各一套，分别评估摊回错配，净准备金不可信
数据缺口 / 迟报对角线最近格异常低最近的点降权（近三年加权法）；或延后评估基准链梯把「还没录进系统的赔案」当作「没发生」
业务结构变化险种构成、免赔额、渠道结构突变分线（险种）评估后汇总；结构变化说明写入报告混线三角形进展模式互相污染
教教材 Ch2 真实数据演示：2010 年总赔款按事故年分组的对角线为 23,000 / 148,000 / 422,000 / 744,000 / 1,007,000 / 1,536,000 / 1,889,000（事故年 2004→2010），配套 2004–2010 已报案 / 已付两套三角形——同一批赔案因分组基准不同（事故年 vs 报告年 vs 保单年）形状完全不同，这正是数据诊断的第一课。
「先问数据三遍」：一问口径（毛/净、直接/间接费用、是否含 ALAE）；二问异常（大案、通胀、流程）；三问成熟度（最近对角线可信吗）。三问答完，方法基本自动浮现。

§4.2模型调整与假设校验

教材 Ch12 的实际问题清单，浓缩成四个「调整动作」——每个动作都对应一类真题场景。

动作一：巨灾与大赔案的分离评估

分离-加回框架
常规未决 = 链梯（剔除巨灾后的三角形）
巨灾未决 = 巨灾模型 / 事件聚合单独评估
总未决 = 常规未决 + 巨灾未决

剔除时注意：不是把整行删掉，而是把该赔案的金额从受影响的格子中减去（案数是否剔除视方法而定——案均法中通常保留案数）。巨灾尾部依赖再保结构（事故超赔 vs 成数），净额口径要等摊回（→专题·再保险准备金）。

动作二：通胀指数化

两步走
① 历史赔款指数化：C'(i,j) = C(i,j) × [I(评估日) / I(i,j 时点)]
② 对 C' 做常规链梯 → 得到「评估日价格水平」的最终赔款
（若预期未来仍有通胀，还需对未来增量加趋势因子）
算例：年通胀 5%，AY1 的 12 月赔款 1001 距评估日 5 年 → 指数化到今天应乘 1.05⁵ ≈ 1.276，即 1277。不调整则老事故年「按 5 年前的物价」预测未来赔付——通胀把进展因子虚高（新事故年贵、老事故年便宜），指数化后因子才反映「纯进展」。

动作三：进展速度变化（理赔提速/放慢）

情形三角形信号因子选择对策
结案提速（系统上线、人手增加）近期行的 12→24 因子低于历史均值近三年原始加权法 / 对近期行加权；说明写入报告
报案迟滞（渠道变更、监管新规）首列值系统性偏低首列降权；或用报告年三角形交叉验证
一次性事件（疫情停工）个别列异常剔除该列异常点后平均，报告披露

动作四：尾部因子的三个来源

来源做法教材例
成熟事故年外推最老事故年实际最终 / 最后观察值1.064 = 3705 / 3483
曲线外推对尾部因子做幂/指数衰减拟合外推长尾责任险常用
行业基准监管或行业公布的最小进展期外因子数据不足时的兜底
尾部是长尾业务最大的估计风险：观察期只有 6 年、真实尾巴 10 年时，尾部因子差 0.1，最终赔款差 10%。大题问「链梯法的局限性」，标准答案第一条就是「尾部外推主观」。常考

§4.3回溯分析（偏差率）——监管重点

回溯 = 拿昨天的预测对今天的实际「对账」。它是准备金体系的免疫系统，也是近年考频上升最快的实务考点。
回溯偏差率（监管口径）
偏差率 =（上期评估日估计的「本期应发生额」− 本期实际发生额）/ 上期估计
（未决口径：比较上期未决估计的消耗进度 vs 实际赔付进展；未到期口径：比较上期 UPR 对应的已赚部分预期 vs 实际）
偏差形态含义修正动作
持续正偏差（高估）准备金释放，当期利润虚增前埋雷（前期多提）下调节奏、检查逐案估损保守度、释放需论证
持续负偏差（低估）本期补提，利润被侵蚀；可能是进展模式变了重估进展因子、检查尾部、补提并披露
符号交替、幅度收敛估计过程受控维持方法与假设
演算器 4-1 · 回溯偏差率（自构例，对齐监管口径）

监管框架（银保监规〔2022〕6号实施细则）：准备金评估结果连续回溯偏差超过监管设定幅度（按险种设定阈值）的，应当分析原因、调整方法或假设并向监管报告。
规银保监规〔2022〕6号（非寿险业务准备金监管有关问题的通知及实施细则1–7号）：建立准备金回溯披露与修正机制，连续偏差超限须说明并整改。教材 Ch7 P175「评估结果检验」与 Ch12 实际问题清单互为印证。
2025回忆真题影子：「简述回溯分析的作用与偏差处理」——答「免疫系统」三层：① 检验假设与方法有效性；② 发现系统性偏差（高估释放 / 低估补提）；③ 触发修正（因子重估、方法更换、监管报告）。常考

§4.4结果检验的四个抓手（教材 Ch7）

算完不是终点。教材 Ch7 给出四个互相独立的检验抓手，大题「如何检验评估结果的合理性」按此作答。
抓手怎么做不合理时的信号
① 赔付率合理性各事故年隐含最终赔付率 = LU / EP，与定价赔付率、行业均值对比某事故年隐含赔付率 120% 而定价 75% → 因子或先验失真
② 多方法交叉链梯 / B-F / 准备金进展 / 案均并列，看差异能否解释方法间差异 >10% 且解释不了 → 数据问题嫌疑最大
③ 分组一致性分险种 / 地区 / 渠道子三角形分别评估后加总 vs 整体直接评估加总与整体显著不等 → 混合三角形掩盖结构差异
④ 逐期回溯上节回溯偏差的时间序列（不只是单期）连续同号偏差 → 系统性，必须修
本库数据实操：用 CH.02 的真实数据算隐含赔付率——链梯法 LU 合计 32825 ÷ EP 合计 37764 = 86.9%；B-F(RC) 隐含 = 31344/37764 = 83.0%（先验锚定的自然结果）；赔付率法 = 83%。三法隐含赔付率落在 83–87% 区间，差异可由「新事故年进展不确定性」解释 → 结果可信。这就是抓手①②的联合用法，考综合题时写出这段推理就是满分答案。
