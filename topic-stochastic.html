随机模型与变异系数（CV）

链梯法只给一个数，随机模型给一个分布 —— Mack 模型 · Bootstrap · 置信区间 · CV 检验（教材 Ch5 P142）

定位拔高专题 · 风险边际与随机准备金的理论底座
一、为什么需要随机模型 二、Mack 模型（解析法） 三、Bootstrap（重抽样法） 四、CV：准备金的体检指标 五、与考点的连接

一为什么需要随机模型

链梯法的 CDF 连乘只回答「点估计是多少」；而风险边际（CH.02 §2.6 的 75% 分位）与偿付能力资本（K2）都需要「分布长什么样」。
视角确定性方法（链梯族）随机模型
输出一个数（点估计）分布（均值 + 方差 + 分位数）
能回答未决「大概是多少」未决超过 X 的概率是多少（VaR 口径）
用途负债入账风险边际计量 · 资本占用 · 管理层沟通区间
代表链梯 / B-F / 案均 / 赔付率Mack（解析方差）· Bootstrap（模拟方差）· 广义线性模型
教教材 Ch5「随机模型」：链梯法的概率化改造——把进展因子看作随机变量，最终赔款成为随机变量。教材用 2001–2010 十事故年三角形演示「推广的链梯比率族模型」（.xls 第五章数据，首行 2001 年：6174 / 8061 / 8639 / 8951 / 9207 / 9363 / 9464 / 9559 / 9634，进展 9 期）。

二Mack 模型（解析法）

Mack（1993）在不指定分布的前提下，只用「进展因子独立 + 方差与均值成比例」两个假设，推出链梯估计的预测方差。
Mack 两条假设 + 方差公式
假设① E[C(i,j+1) | C(i,j)] = f(j)·C(i,j)　（链梯关系的期望形式）
假设② Var[C(i,j+1) | C(i,j)] = σ²(j)·C(i,j)　（方差随规模放大）
参数估计：f̂(j) 即加权链梯因子；σ̂²(j) = 1/(n−j−1) · Σ C(i,j)·[f(i,j) − f̂(j)]²
预测误差（MSEP）：s.e.(LU(i)) = LU(i)·√[ Σ(j≥当前) σ̂²(j)/f̂(j)² · (1/C(i,j) + 1/S(j)) ]

直观拆解：预测方差 = 过程方差（σ² 部分，赔款固有的随机性）+ 参数方差（1/S(j) 部分，因子估计的抽样误差——暴露量 S(j) 越大，因子估得越准）。新事故年两块都大，老事故年两块都小——与链梯「新年份不确定」的直觉完全一致。

考试定位：正精算师（非寿险）对本专题要求「懂框架、会解释」，不要求手推 MSEP。大题若问「如何量化准备金评估的不确定性」，标准答案：Mack 解析法（假设少、快）或 Bootstrap（模拟法、可给完整分布），二者都输出 s.e. 与置信区间，支撑 75% 分位风险边际。

三Bootstrap（重抽样法）

Mack 硬算方差，Bootstrap 直接「把历史重演一万遍」——用重抽样生成一万个未来，看未决的分布。
Bootstrap 五步流程
残差重抽样 · England & Verrall
① 拟合

对增量三角形拟合链梯（或 GLM），得到拟合值与 Pearson 残差。

② 重抽残差

把调整后的残差放回池中，有放回地重抽样，生成「伪历史三角形」。

③ 重估因子

对每个伪三角形重跑链梯，得到一组的进展因子与下三角预测（参数不确定性）。

④ 加过程噪声

对预测的未来增量再按伽马/过度散布泊松分布抽样（过程不确定性）。

⑤ 汇总分布

一万个总未决 → 直方图 → 均值、标准差、任意分位数（含 75%）。

Mack 与 Bootstrap 结果通常接近（同源于链梯结构）；Bootstrap 的额外福利是可以输出按事故年 / 按进展期的二维分布，管理层沟通直观。

四CV：准备金的体检指标

CV（变异系数）= 标准差 / 均值——把「不确定性」换算成可横向比较的百分比。
CV 与经验区间
CV = s.e.(CV准备金) / CV准备金均值
经验标尺（长尾业务）：CV < 10% 健康 · 10–20% 正常 · > 20% 数据或方法警报
业务典型 CV 量级驱动因素
车险（短尾）3–8%数据厚、进展短、模式稳
财产险（中尾）8–15%大额赔案扰动
责任险（长尾）15–30%+尾部因子主观 + 司法环境漂移
CV 的三个用法：① 同一业务逐期监控——CV 突升说明数据异常或结构突变；② 跨险种资本配置——CV 高的险种 K2 因子天然更重；③ 风险边际校准——75% 分位 ≈ 均值 + 0.674×s.e.（正态近似），s.e. 由 Mack/Bootstrap 给出，风险边际 = 0.674×s.e.，与资本成本法互为校验。常考
