量化风险最低资本

保险风险（非寿险）拆解

赔付波动风险（保费及近期赔付经验暴露）+ 准备金发展风险（未决净额暴露）+ 巨灾风险（灾因暴露）——即 K1 / K2 / K3。

控制风险调整

操作与治理缺陷带来的附加（+）或减免（−），与 19 号内控规范（→CH.05 §5.3）直接挂钩。

记忆锚：保险风险是「承保与估计」的资本化；市场风险是「投资」的资本化；信用风险是「对手方」的资本化。准备金评估师主场在 K2。

二K1 / K2 / K3 的计量框架

模块风险暴露 EX风险因子结构特色调整
K1 赔付波动自留保费 / 已赚保费口径（规模）基础因子×(1+特征系数)：特征含险种结构、再保结构、赔付经验偏差近年赔付率异常 → 因子上浮
K2 准备金发展未决赔款准备金净额（摊回后）基础因子×(1+特征系数)：特征含回溯偏差历史、长尾占比、三角形成熟度连续负偏差回溯 → 因子上浮（估不准要多占资本）
K3 巨灾按灾因（台风/洪水/地震/冰雹…）的风险暴露与区域集中度灾因情景/概率模型计量；分灾因后高相关聚合区域集中度加成；农险、财产险为主要载体
聚合的两层结构（框架级）
第一层（险种内）：MC(险种) = √[ K1² + K2² + 2·ρ12·K1·K2 ]
第二层（险种间）：MC(保险风险) = √[ Σi Σj ρij·MC(i)·MC(j) ]　（ρii=1，ρij 按险种对设定，均 < 1）
巨灾部分 K3 通常以更高相关系数参与聚合（趋于线性相加）
规银保监发〔2021〕51号附件第4号（因子表与相关系数矩阵以附件原文为准，本站给框架）
为什么 ρ < 1 是「资本优惠」：两个不完全相关的风险叠加，总波动小于简单相加（分散效应）。险种越多元，第二层的分散红利越大——这是「业务结构影响资本占用」的数学根源，论述题用它解释多元化战略。常考

三险种与聚合结构

险种群尾部特征K2 因子量级直觉准备金评估要点
车险（车损/三责）短-中尾低（进展短、数据厚）链梯为主，人伤三责稍长
企财险 / 家财险中尾，巨灾暴露中（大案扰动）巨灾分离 + B-F
责任险（公众/产品/职业）长尾高（IBNR 占比大、尾巴长）B-F 为主，尾部因子重点论证
农险季节性 + 巨灾中-高（时空相关）风险分布法 + 事件模型（→专题·农险）
意健险（短期）短尾低赔付率法即可，关注逆选择
信用保证险与经济周期共振特殊（系统性）宏观情景叠加，谨慎性加倍
演算示例（自构，框架级）：某公司 K1 = 8 亿、K2 = 5 亿、ρ12 = 0.5 → 险种内 MC = √(64+25+2×0.5×8×5) = √129 ≈ 11.36 亿；若 ρ12 = 0（完全分散）→ √89 ≈ 9.43 亿；若 ρ12 = 1（完全同向）→ 13 亿。相关系数从 1 降到 0.5，资本省 1.64 亿——风险相关性就是资本价格。

四准备金评估师的资本视角

把 CH.02–CH.04 的每个技术选择翻译成 K2 的语言——这是「准备金评估对经营管理影响」的高阶答案。
评估技术选择K2 后果经营含义
链梯 vs B-F（结果差 8%）未决净额差 8% → K2 差同比例方法选择的资本成本要进决策
尾部因子 +0.1（长尾险种）未决↑ → K2↑，且尾部越远折现越少尾部论证质量 = 资本效率
回溯连续负偏差特征系数上浮（双重惩罚：补提+因子升）回溯纪律是最便宜的资本管理
再保超赔结构优化K2 净额下降 vs 信用风险上升三元优化（→专题·再保 §四）
随机模型给出的 s.e.K2 本质上就是对 s.e. 的监管定价估得准（s.e. 小）≈ 资本省（→专题·随机模型）
2024回忆2025回忆真题影子：「准备金评估结果与偿付能力的关系」——四层递进：① 未决净额是 K2 暴露 → ② 估计上调节接推高最低资本 → ③ 回溯质量影响特征系数 → ④ 结论「准确、可回溯的评估本身就是资本节约」。第④层是拉开档次的收束句。高频必背
