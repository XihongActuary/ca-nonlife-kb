§3.1基本概念与未赚保费逻辑

未到期责任准备金（UPR）= 未赚保费对应的负债：评估日之后仍在保障期内的那部分保费收入。
核心恒等式
已赚保费 = 保费收入 − Δ未到期责任准备金
UPR = 保费收入 × 未到期比例（比例法）
UPR = 未来风险暴露对应保费（风险分布法）
教谢志刚 Ch8 P194 起

三层理解：

  1. 时间切分：一年期保单的保障期横跨评估日，保费按「已提供保障 / 未提供保障」切成两段——已赚部分进损益，未赚部分留在负债。
  2. 与未决的本质区别：未决对应「已发生的保险事故」（过去时），未到期对应「尚未发生的风险」（将来时）。未决靠三角形回望，未到期靠暴露前瞻。
  3. 充足性是底线：比例法算出的只是「未赚的保费」，不保证够赔——赚得不够赔时，用保费充足性测试补提保费不足准备金（→§3.5）。
规银保监会令2021年第11号：未到期责任准备金评估应当采用未赚保费法（1/365法等）或者风险分布法等方法；采用其他方法的，应当说明理由。

§3.2比例法（1/365 · 1/24 · 1/8）

假设风险随时间均匀分布，未到期比例 = 剩余天数 / 保险期间总天数。三种粒度，精度与工作量递增。
方法粒度假设未到期比例（评估日 12-31，保单当年 3 月起保）适用
1/365 法（逐日）天无需假设，按保单起保日精确切分剩余 62 天 / 365信息系统支持逐单处理（现行主流）
1/24 法（月）月月内均匀出单，视同月中起保2.5 / 12按月汇总数据（传统手工口径）
1/8 法（季）季季内均匀出单，视同季中起保1.5 / 4按季度汇总数据（粗略）
1/24 法演算（3 月保单，年保费 1200）
3 月签单视同 3 月 15 日起保 → 至 12-31 已保障 9.5 个月，剩余 2.5 个月
未到期比例 = 2.5/12 = 0.2083　→　UPR = 1200 × 0.2083 = 250；已赚 = 950
1/24 的「0.5 从哪来」：假设当月 15 日出单，当月已保障半月——所以签单当月按 0.5 个月计已赚。1/8 同理：签单当季按 0.5 季（1.5 个月）计已赚。考试爱问「1/24 法隐含假设是什么」——答「各月内出单均匀，等价于月中集中出单」。
易错点：① 跨年度保单（如 2024-07-01 至 2025-06-30）在 2024 年末评估时剩余 6 个月，未到期 = 1/2，别按「当年内剩余」算；② 保费不足准备金不冲减 UPR，而是单独列示（→§3.5）；③ 1/365 法不需要均匀假设，是三种方法中唯一「无假设」的。高频必背

§3.3风险分布法

风险不随时间均匀分布时（季节性、事件性风险），按「未来风险暴露占比」而非「剩余时间占比」计提。
方法框架
UPR = 保费 × [Σ(评估日后各期风险暴露权重)] / [Σ(全保险期间风险暴露权重)]
暴露权重可取：历史各期出险频率 / 行业风险分布 / 事件触发概率
业务风险分布特征均匀假设的偏差风险分布法处理
种植险 / 洪涝险风险集中在 6–9 月年末按时间比例计提偏高（冬春风险小）按生长期各月出险概率分配暴露权重
建筑工程险随施工进度（基础→结构→装修）递变时间比例与风险暴露错位按工程造价进度曲线分配
货物运输险随运输批次脉冲式均匀假设严重失真按未来运输计划（航次/吨公里）暴露
意外险（日常）基本均匀偏差小用 1/365 即可（无需风险分布法）
算例（洪涝险）：年保费 800，风险暴露权重：1–5 月各 0.5、6–9 月各 3、10–12 月各 1（合计 12）。评估日 12-31，未来只剩 1–5 月（权重合计 2.5）。UPR = 800 × 2.5/12 = 167；若误用 1/24（5/12 = 0.4167）则计提 333——高估一倍。风险分布法不是「更精细的装饰」，而是季节性业务的方向性纠偏。
2023回忆真题影子：「哪些业务适合用风险分布法评估未到期责任准备金？说明理由」——按上表逻辑答「风险暴露与时间显著不匹配的业务 + 一句假设对比 + 一个例子」，再补「银保监会令2021年第11号允许并鼓励更合理方法」收尾。常考

§3.4长期合同未到期责任

保险期间一年以上的非寿险合同（工程险长期保单、船舶险、融资性信保等），时间切分之外还要看赔付节奏。
维度一年期合同长期非寿险合同
未到期评估1/365 / 1/24 / 风险分布风险分布法为主（暴露跨多年）；或按合同约定赔付节点切分
数据成熟度1 年内见分晓多年进展，兼有未决三角形的长期性
充足性测试年度滚动测试应覆盖整个剩余期间的全部预期流出
折现通常不折现期限长，应当考虑折现（11号令：考虑货币时间价值）

§3.5保费充足性测试（保费不足准备金）——每年必考

比例法只保证「账算得平」，不保证「钱够赔」。充足性测试是监管强制的安全阀：测试失败 → 补提保费不足准备金（PDR）。
测试逻辑（财会〔2009〕15号口径）
预期未来流出 = UPR × [预期赔付率 + 理赔费用率 + 维持费用率 + 营业税及附加率]
若 预期未来流出 > UPR → PDR = 预期未来流出 − UPR（补提，进当期损益）
若 预期未来流出 ≤ UPR → 测试通过，PDR = 0（超额部分不得转回利润）
规财会〔2009〕15号：充足性测试应考虑未来发生赔款、理赔费用、营业税及附加及维持费用等

完整算例（自构，对齐监管口径）

某公司车险业务年末未到期责任准备金 UPR = 8000万元。精算评估未来预期：赔付率 82%、理赔费用率 3%、营业税及附加率 5.5%、维持费用率（展业及管理分摊）16%。

与寿险 F3 的对照（跨库）：寿险的「准备金充足性测试」比较的是未来现金流现值 vs 账面准备金（负债端整体）；非寿险的「保费充足性测试」比较的是未赚保费 vs 预期流出（保费端）。一个问「准备金够不够」，一个问「保费够不够」——名词一字之差，对象完全不同。
