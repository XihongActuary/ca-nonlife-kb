模拟卷三 · 实务综合

对应 CH.04 评估实务 + 专题群（再保 / 随机模型 / 风险边际）——「实务多过理论」的 20–30 分分差之地
题型：单选×5 · 多选×3 · 计算大题×3 · 论述×2 满分 100 分：单选 10 + 多选 6 + 计算 60 + 论述 24 建议用时 150 分钟 · 论述先写框架再填内容
本卷覆盖考纲主题CH.04 + 专题群

本页为练习页，不计入学习进度。卷三冲实务：回溯全流程、再保摊回、风险边际——没做过实务的考生在这里最容易丢分（考生原话：「没做过实务的只能靠想象凭运气」）。本卷每道计算题都配「跨部门沟通」式的论述小问，模拟真实考法。

卷三第一部分 · 单项选择题（每题 2 分，共 10 分）

1. 某季度已决赔款显著高于预期，但赔案件数与案均均未异常、报案件数正常。最可能的解释是：

A. 赔付水平永久恶化　B. 结案速度加快（存量估损集中释放）　C. 逆选择加剧　D. 定价不足

答案：B。件数、案均不变而已决突增 = 结案提速、存量 RV 集中释放——终极不变，只是流出提前。此时因子重估即可，勿误判为恶化（2025 原题「三种走势」之一）。

2. 累积损失服从 Tweedie 分布（1 < p < 2），累积损失等于零的概率为：题总结·3

A. 0　B. e^(−λ)（复合泊松计数为零的概率）　C. 1　D. 无法计算

答案：B。Tweedie 在 1<p<2 时是「质量点 0 + 连续正部」的复合泊松-伽马混合，P(X=0) 就是泊松为零的概率。

3. 融资性信用保证保险的监管处理中，除保险风险最低资本外，还要求：

A. 计提专项风险准备金（超额损失缓冲）　B. 只需提高偿付能力报告频率
C. 无额外要求　D. 转为表外披露

答案：A。「资本 + 准备金」双层防御——融资性信保是 2025 年的加码考点（偿二代小白书），出题密度显著上升。

4. 风险边际的置信区间法下，75% 分位准备金与最优估计的关系（正态近似）是：

A. μ + 0.674σ　B. μ + 2.326σ　C. μ + 2.576σ　D. μ − 0.674σ

答案：A。75% → 0.674σ；99% → 2.326σ；99.5% → 2.576σ——三个 z 值背熟，2024「100 年一遇」考的就是 2.326。

5. 准备金评估前数据准确性检验中，「对角线整体异常」最可能提示：

A. 巨灾事件　B. 数据补录或系统切换　C. 通胀趋势　D. 尾部因子低估

答案：B。巨灾影响集中在特定事故年（一列），数据/系统问题集中在特定日历年（对角线）——「列 vs 对角线」是数据诊断的罗盘（CH.04 §4.1）。

卷三第二部分 · 多项选择题（每题 2 分，共 6 分）

6. 下列哪些情形会破坏流量三角形数据的可比性，需要评估前处理？

A. 立案标准调整　B. 恶性通胀时期　C. 再保分出结构变化　D. 理赔外包供应商更换　E. 保费规模自然增长

答案：A、B、C、D
A（报案情势）、B（货币尺度）、C（毛净口径）、D（结案节奏/费用）都是「数据问题六类」的成员；E 是正常经营，只要费率与业务质量同步稳定就不构成数据问题。六类框架见 CH.04 §4.1。

7. 发现某季度准备金计提异常上升后，评估岗应沟通的部门与确认的问题包括：

A. 承保部——新单结构与核保政策变化
B. 理赔部——报案/立案/结案节奏与估损政策
C. 再保部——分出结构与摊回数据完整性
D. 人事部——薪酬结构调整
E. 财务部——科目口径与报送时点

答案：A、B、C、E
「三个部门带问题清单」是 2025 原题的标准答法（承保/理赔/再保）；财务口径核对是评估岗的基本功。完整问题清单见 真题馆 Z.2 实务题样板。

8. 回溯出现不利偏差后，提升准备金评估充足度的合理措施包括：

A. 多方法并算取审慎值
B. λ、尾部因子、通胀假设向不利方向校准并留档理由
C. 风险边际按 75% 分位复核充足性
D. 一次性大幅补提且不再回溯
E. 重大假设变更走内控审批

答案：A、B、C、E
D 违背回溯的连续性原则——偏差处理是「归因 → 校准 → 披露」的持续过程，不是一锤子买卖（2023·大15 原题）。

卷三第三部分 · 计算大题（每题 20 分，共 60 分）

九、（20 分）回溯分析全流程

题目：2022 年末评估时，2020–2022 三个事故年的累计已决赔款与选定进展因子如下（单位：万元）：

事故年累计已决（2022 末）进展因子 f
20201,0001.10
20212,0001.25
20222,4001.60

2023 年末，累计已决变为 1,060 / 2,150 / 3,000；重新评估的终极赔款为 1,120 / 2,560 / 3,900。不折现，风险边际率 5.5%。

要求：（1）计算 2022 年末计提的未决赔款准备金（含边际）（8 分）；（2）回溯 2023 年：计算当年实际消耗、不利偏差与偏差率（8 分）；（3）写出偏差超边际后的处理三句话（4 分）。

展开详尽答案

（1）2022 年末：终极 = 1,100 / 2,500 / 3,840；未决 = 100 / 500 / 1,440，合计 2,040；含 5.5% 边际计提 = 2040×1.055 = 2,152.2。

（2）2023 年回溯：当年已决增量 = 60 + 150 + 600 = 810；年末剩余未决 = (1120−1060) + (2560−2150) + (3900−3000) = 60+410+900 = 1,370；实际消耗 = 810+1370 = 2,180；不利偏差 = 2040 − 2180 = −140；偏差率 = −140/2040 = −6.9%。

（3）处理三句：① 偏差率 −6.9% 为不利偏差，超出 5.5% 风险边际的覆盖能力（边际吸收 5.5 个百分点，实际偏差 6.9 个百分点）；② 按银保监规〔2022〕6号，当年补提 140 万元进损益，并在精算报告中披露偏差原因；③ 回溯底稿记录因子修正建议（2021/2022 年进展因子低估 4–7%）。与 CH.04 §4.3 演算器 4-1、真题馆 Z.2 样板三 同源（2024 大题3 原型）。

十、（20 分）再保险准备金与摊回

题目：某公司安排超赔再保：赔款 100 万元以内自留，100–250 万元 layer 由再保人承担 80%（另 20% 共担），250 万元以上无再保。

要求：（1）某大案最终赔款 180 万元，计算再保摊回与自留额（6 分）；（2）另一案件最终赔款 260 万元，计算摊回与自留额，说明「层满回归」现象（8 分）；（3）说明毛/净三角形分设原则与摊回的信用风险（6 分）。

展开详尽答案

（1）180 万：超 layer 部分 = 180−100 = 80 万 → 摊回 = 80×80% = 64 万 → 自留 = 180−64 = 116 万。

（2）260 万：超 layer 部分 = min(260,250)−100 = 150 万 → 摊回 = 150×80% = 120 万 → 自留 = 260−120 = 140 万。层满回归：赔款从 250 万涨到 260 万（+10 万），摊回不再增加（已封顶 120 万）——超赔保护的「非线性」：层内保护、层上裸奔，损失重新 100% 回到自留。含义：评估净额三角形时，大案的边际增长直接冲击净额，毛/净三角形差异随大案规模非线性放大。

（3）铁律：毛、净三角形分设分估（不能先估毛再乘比例——超赔的非线性使比例近似失真）；摊回确认为再保资产，但交易对手违约风险由偿二代信用风险模块计资本——「再保买的是净额下降，付的是信用风险」（专题·再保险准备金，2024 大题5 原型）。

十一、（20 分）风险边际与产品线分摊

题目：公司未决赔款准备金最优估计（期望）μ = 5000 万元，整体变异系数 CV = 12%。公司 4 条产品线的偿付能力最低资本分别为 3.2 / 2.6 / 1.8 / 0.9 亿元，合计 8.5 亿元；公司层面风险边际总额 1020 万元。

要求：（1）按 100 年一遇（99% 分位）计算准备金余额与风险边际（8 分）；（2）计算风险边际率（4 分）；（3）按最低资本占比将风险边际分摊到第 4 条产品线（8 分）。

展开详尽答案

（1）σ = 5000×12% = 600；99% 分位准备金 = 5000 + 2.326×600 = 6,395.6 万元；风险边际 RM = 6,395.6 − 5000 = 1,395.6 万元。（对照：200 年一遇 99.5% → 2.576σ → RM = 1,545.6——分位越高边际越厚，这就是「百年 vs 二百年一遇」的量化含义。）

（2）风险边际率 = 1395.6 / 5000 = 27.9%。

（3）第 4 条线最低资本占比 = 0.9 / 8.5 = 10.59% → 分摊风险边际 = 1020 × 10.59% ≈ 108 万元。逻辑：风险边际度量负债超越期望的尾部代价，最低资本是各业务块风险的监管定价——同一定价尺度下按占比分摊最公平。与 真题馆 Z.4 样板五 同例（2024 大题7 原型）。

卷三第四部分 · 论述题（每题 12 分，共 24 分）

十二、（12 分）准备金评估对经营管理的影响

题目：结合监管规则，论述非寿险责任准备金评估结果如何影响公司经营管理。

骨架：五传导路径——利润表 → 偿付能力 → 产品定价 → 再保安排 → 投资与 ALM；每条挂一个文号。
展开详尽答案
传导路径机理文号（得分点）
① 利润表与承保利润Δ未决直接进损益，估计上调节节吞噬当期利润财会〔2009〕15号
② 偿付能力未决净额是 K2 暴露，估计上调推高最低资本、压低充足率银保监发〔2021〕51号附件4
③ 产品与定价充足性测试失败提示费率不足，PDR 是定价信号灯11号令 + 农险4号文
④ 再保安排净额口径的未决结构决定摊回资产质量；长尾 K2 高→超保降资本偿二代信用风险模块
⑤ 投资与 ALM未决的久期与支付节奏约束资产端流动性配置11号令（时间价值）

收束句（拉开档次）：「准确、可回溯的准备金评估本身就是资本节约与经营稳定的公共品——估得准，K2 的资本占用与回溯的补提冲击同时下降。」完整版见 CH.05 §5.4 五大经营传导。

十三、（12 分）实务综合：赔款高于预期之后

题目：你是车险公司评估岗，发现一季度已决赔款显著高于预期。请回答：（1）后续未决赔款可能的三种走势及原因（6 分）；（2）应分别采用什么方法评估（3 分）；（3）列举你准备沟通的三个部门及各想问的问题（3 分）。

骨架：三走势 = 一次性脉冲（终极小移）／水平抬升（终极上移）／进展加速（终极不变）；方法各对一种；三部门 = 承保、理赔、再保，各带 2–3 问。
展开详尽答案
走势原因对终极的影响评估方法
① 脉冲后回归巨灾 / 单一大案小幅上移巨灾分离 + 基础三角形原方法
② 水平永久抬升通胀 / 法规 / 费率不足系统性上移通胀指数化 + B-F（λ 上调）
③ 仅进展加速结案提速不变近期因子重估，勿误判恶化

三部门问题清单：承保部——新单结构 / 核保规则有无主动调整？有无新险种？理赔部——报案量激增是真实出险还是集中补报？立案阈值、结案节奏、首次估损保守度有无变化？再保部——分出结构本季有无变化？摊回数据是否完整滞后？收束：「先定位、再验证、后沟通、最后才调方法」——这套顺序本身就是答案的一部分（2025 原题 + 真题馆 Z.2 两道实务题合编）。
