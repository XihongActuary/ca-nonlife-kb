§1.1为什么需要责任准备金

非寿险（财产险、意外险、健康险短险）的赔付是「先收费、后发案、再赔付」——保费落袋的那一刻，负债刚刚开始。
核心恒等式
评估日责任准备金 = 未来预期赔付与费用的现值 + 风险边际
教谢志刚 Ch1 P16–20

三点理解：

  1. 负债属性：准备金是资产负债表上最大的负债科目（非寿险公司通常占总负债 60% 以上），评估多一分，利润少一分；评估少一分，偿付能力虚高一分。教
  2. 两段负债：保费对应的保障期横跨评估日——已赚部分对应未决赔款准备金（已发生、未赔完），未赚部分对应未到期责任准备金（未到期、保障还在）。
  3. 不确定性：未决的金额靠估计（IBNR 不可观测），未到期的发生概率靠假设（赔付率先验）——所以叫「评估」valuation 而不是「计量」mere recording。规银保监会令2021年第11号第三条：准备金评估应当遵循谨慎性原则。
记忆钩子：「一个评估日，切出两段负债」——评估日之前的保障已生效、赔案在途 → 未决；评估日之后的保障未生效、风险未到期 → 未到期。

未到期责任准备金族定义评估方法（→CH.03）
未到期责任准备金（UPR）未赚保费对应的负债比例法（1/365、1/8、1/24）· 风险分布法

未决赔款准备金族定义评估方法（→CH.02）
已报案未决（RBNS / RV）已报告、尚未结案的估损逐案估计法 · 案均赔款法
IBNR（已发生未报告）已发生、未报告（含发展不足）链梯 · 准备金进展 · B-F · Cape Cod · 赔付率法
理赔费用准备金ALAE（可直接归属）+ ULAE（间接）比例法：已付ALAE/已付赔款 · ULAE 72法则族
风险边际不确定性加成资本成本法（75%分位）· 置信区间法
总准备金（考试最常考的拆解）
总未决 = Σ(已报案未决 RV) + Σ(IBNR) + Σ(ULAE) + 风险边际
资产负债表未决 = 已报案未决（含逐案估损与案均） + IBNR（含B-F等法） + 理赔费用准备金
规银保监会令2021年第11号附件口径
易错点：① ULAE 属于未决赔款准备金的一部分，不是独立科目；② 保费不足准备金属于未到期族的补充计提，挂在 UPR 之外单独列示；③ 理赔费用准备金分 ALAE（可归属，随逐案估计）与 ULAE（不可归属，按比例摊），考试问「间接理赔费用」指 ULAE。高频必背

§1.3三类时间基准与流量三角形

流量三角形（run-off triangle）是全科的「操作台」。选错时间基准，后面所有方法都白算。
基准行（grouping）列（进展）适用典型场景
事故年 AY赔案发生日所在年度发生→报告→赔付的进展月/年IBNR 评估首选车险、财产险——以「发生」为准，报告迟早不影响行归属
报告年 RY赔案首次报告日所在年度报告→赔付的进展已报案未决进展 / 无报告迟滞数据时教材 Ch4「报告年准备金进展法」用 RV 三角形
保单年 PY保单生效日所在年度生效→发生的进展保单质量分析、定价反馈同一年签发的保单同质性强，但数据最不成熟
三角形两种形态（考试必须会互换）
累计（cumulative）：C(i,j) = Σ增量 · 用于链梯法
增量（incremental）：X(i,j) = C(i,j) − C(i,j−1) · 用于B-F分步、随机模型
实操直觉：拿到数据先问三个问题——① 行是事故年还是报告年？② 数字是累计还是增量？③ 右下角缺格的「对角线」是评估日吗？三个答案确定后，方法选择基本就定了：累计三角形 + 均匀进展 → 链梯；报告不稳定 + 有先验赔付率 → B-F。

年2：1113 / 2103 / 2774 / 3422 / 3844
年3：1265 / 2433 / 3233 / 3977；年4：1490 / 2873 / 3880；年5：1725 / 3261；年6：1889

§1.4评估流程总览

监管规定的评估流程是实务题的「程序模板」——回答任何「如何评估」的大题都按这五步走。
准备金评估五步流程
数据 → 假设 → 方法 → 结果 → 报告
① 数据收集与诊断

理赔明细、保费台账、再保摊回口径核对；识别异常（大赔案、通胀、司法环境变化、理赔流程变更）。→ CH.04 §4.1

② 假设设定

进展模式、先验赔付率、通胀率、折现率、尾部因子。每个假设都要有历史数据或行业基准支撑。→ CH.04 §4.2

③ 方法选择与计算

未决四法 + 未到期两法 + ULAE 比例法；多方法互证，取值说明理由。→ CH.02 / CH.03

④ 结果检验与回溯

赔付率合理性检验、逐期回溯偏差分析、与上期结果对比解释差异。→ CH.04 §4.3 + 教材 Ch7

⑤ 报告与内控

出具准备金评估报告，精算责任人签署；底稿留档、内部控制流程。→ CH.05 §5.3（11号令 + 19号内控规范）

2024回忆真题影子：「简述非寿险准备金评估的主要流程及各环节的关键控制点」——按五步流程作答，每步点出 1 个关键控制点（数据：完整性核对；假设：有依据可回溯；方法：多方法互证；检验：回溯偏差率；报告：精算责任人签署）即可拿满分结构分。常考

§1.5非寿险 vs 寿险评估的差异

跨科目对照题的送分点，也是从 F3 转战本过来的考生最需要的定位表。
维度非寿险（本科目）寿险（F3）
负债主体未决赔款（估过去已发生）+ 未到期（赌未来发生）责任准备金（未来保费+给付的精算现值差）
核心工具流量三角形、进展因子生命表、现金价值、评估利率
风险边际资本成本法 / 置信区间法（折现可选）评估利率审慎 + 均衡纯保费机制
数据成熟度短尾业务 1–2 年，长尾可达 10 年+保单期限数十年，利率风险主导
充足性机制保费充足性测试（整体业务层面，补提 PDR）准备金充足性测试（未来现金流现值 vs 账面准备金）
监管重心偿二代Ⅱ保险风险最低资本 K1/K2/K3利率风险 / 身故风险最低资本
题2008 完整卷简答题考过「非寿险准备金与寿险准备金的本质区别」——答「赔付发生的可观测性」（寿险给付事件确定、金额契约化；非寿险赔案发生与报告均滞后、金额估损）是得分关键句。
