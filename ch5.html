§5.1保险风险最低资本（K1 / K2 / K3）

偿二代Ⅱ（银保监发〔2021〕51号附件第4号）把非寿险保险风险拆成三块：赔付波动（K1）、准备金发展（K2）、巨灾（K3）——其中 K2 与本科目「血肉相连」：准备金估错直接吃掉偿付能力。
风险模块风险来源风险暴露 EX 的口径与准备金评估的接口
K1 赔付波动风险承保结果偏离预期（费率不足 / 频率强度波动）保费口径：自留已赚保费（或自留保费）规模充足性测试失利率（PDR 规模）是其恶化信号
K2 准备金发展风险未决赔款准备金未来发展偏离估计未决赔款准备金净额（扣除摊回后）直接接口：链梯/B-F 的估计误差 → K2 资本占用
K3 巨灾风险台风 / 洪水 / 地震等灾因的聚合损失按灾因的风险暴露（区域集中度加成）巨灾未决的分离评估（→CH.04 §4.2）对应此处资本
计量框架（框架级公式，具体因子表见附件4）
单个风险模块：K = EX × RF ×（1 + 特征调整系数）
险种内聚合：MC(险种) = √[ K1² + K2² + 2·ρ12·K1·K2 ]　（赔付波动与准备金发展相关系数 ρ12 < 1）
险种间聚合：MC(保险风险) = √[ ΣΣ ρij·MCi·MCj ]　（险种间相关性按矩阵设定）
巨灾模块按灾因分别计量后高相关聚合（趋于直接相加）
规银保监发〔2021〕51号《保险公司偿付能力监管规则（Ⅱ）》附件第4号
传导链示例（自构数字）：某财险公司未决净额 10 亿，K2 风险因子 5% → K2 = 5000 万。若回溯发现长尾业务持续负偏差、准备金补提 10% → 未决升至 11 亿 → K2 增至 5500 万 → 最低资本上升 → 核心偿付能力充足率下降。「准备金每多估 1 亿，偿付能力被占用一档」——这条链是论述题「准备金评估对偿付能力影响」的标准答案骨架。
深度延伸：因子表、相关系数矩阵、险种分类（车险 / 财产险 / 责任险 / 农险 / 意健险…）的完整展开见 专题·保险风险最低资本 与跨库的 C-ROSS II 偿付能力知识库（口径同源互证）。常考

§5.2会计处理（财会15号）

财会〔2009〕15号《保险合同相关会计处理规定》：非寿险准备金的科目体系、计量属性与损益流转——会计题的「科目对照表」。
科目计量损益流转
未到期责任准备金未赚保费法（1/365 等）/ 风险分布法提取 / 转回「未到期责任准备金」科目进当期损益
保费不足准备金充足性测试差额测试失败补提，计入当期损益（承保亏损显性化）
未决赔款准备金已报案（逐案+案均）+ IBNR + 理赔费用提取 / 转回「未决赔款准备金」科目进当期损益
再保摊回摊回未决 / 摊回未到期，与净额口径对应冲减负债、确认摊回赔付支出
利润表的准备金语言
承保利润 ≈ 已赚保费 − 已发生赔款 − 手续费及佣金 − 营业税金 − 业务及管理费
其中：已赚保费 = 保费收入 − ΔUPR；已发生赔款 = 已付赔款 + Δ未决赔款准备金（含 PDR 影响）
高频陷阱：① 「多提准备金 = 利润减少」——计提是负债增加，通过提取科目费用化；② UPR 的变动影响已赚保费（收入端），未决的变动影响已发生赔款（成本端）——两条线不要串；③ 再保摊回是资产（应收摊回），不是负的准备金科目。高频必背
20082024回忆真题影子：「充足性测试失败对财务报表的影响」：负债端 UPR 不变 + PDR 新增 → 当期提取费用增加 → 承保利润下降 → 同时提示 K1 恶化（费率不足信号）。三层递进作答。常考
新旧准则衔接：财会15号（含保险合同准备金、充足性测试、风险边际隐含在审慎假设中）→ 2023 起新保险合同准则（对应 IFRS17 / CAS25）：未到期责任准备金被拆进「未到期责任负债 + 保险合同财务变动」，显性风险边际变成「非金融风险调整」。完整对照见 专题·财会15号与IFRS17衔接。

§5.3评估报告 · 内控 · 底稿

11号令（管理办法）定义务，19号文（内控规范）定流程——两份文件合起来就是「程序题」的全部答案。
制度要点出处内容速记
评估频率11号令至少每季度评估一次；出现重大事件及时重估
签署责任11号令精算责任人（总精算师）签署准备金评估报告，对假设与方法负责
回溯义务11号令 + 2022年6号细则定期回溯，连续偏差超限须分析、整改并向监管报告
谨慎性原则11号令第三条不得高估资产、低估负债；假设有依据、可回溯
治理架构保监发〔2012〕19号董事会最终责任 → 管理层组织实施 → 精算部门独立评估 → 理赔/财务/再保部门数据支持；职责分离
流程控制19号文数据核对、方法论证、多人复核、结果审批的留痕链条
底稿留档19号文评估底稿、数据来源、假设依据完整保存备查（长期保存）
内控答题模板「四分离 + 三留痕」：四分离——评估（精算）、数据（理赔/财务）、审批（管理层/董事会）、签署（精算责任人）职责分离；三留痕——假设有依据、过程有复核、结果有底稿。任何内控简答套此模板。

§5.4准备金对经营管理的影响

考纲最后一项「对经营管理的影响」——论述题压轴。四条业务线 + 一条监管线，五条传导路径。
准备金评估的五大经营传导
承保 · 理赔 · 再保 · 财务 · 偿付能力
→ 承保与定价

PDR 补提 = 费率不足的市场化警报；隐含赔付率回传定价端，指导费率调整与核保政策收紧。

→ 理赔管理

回溯正偏差提示逐案估损保守（资金沉淀）；负偏差提示估损不足或结案拖沓——理赔KPI 的精算校准器。

→ 再保安排

净额口径的未决结构决定摊回资产质量；长尾险种 K2 高 → 用再保（超赔/成数）降低净敞口与资本占用。

→ 财务与利润

准备金是最大的利润调节阀（也是最大的审计焦点）；计提政策的连续性与回溯纪律决定利润质量。

→ 偿付能力（监管）

K2 直接挂接未决规模；准备金每上调，最低资本同步上升——「估得准」本身就是资本节约。

论述题答题顺序：先总（准备金 = 负债之锚，牵一发而动全身）→ 五条路径各一句 → 收尾（准确评估是经营与监管的双重要求）。
2024回忆真题影子：「结合监管规则论述准备金评估结果如何影响公司经营管理」——按五传导路径作答，每条点出对应监管文号（PDR→财会15号；回溯→2022年6号；K2→偿二代Ⅱ附件4），文号就是得分点。高频必背
